# Система управления библиотекой

Проект представляет собой систему управления библиотекой.

Система предназначена для учета книг, читателей, экземпляров книг, бронирования, выдачи и возврата литературы.

## Основные возможности

- просмотр каталога книг;
- поиск книг по названию и автору;
- бронирование книги;
- регистрация читателей;
- выдача и возврат экземпляров книг;
- контроль просроченных возвратов;
- формирование отчетов;
- управление пользователями и правами доступа.
